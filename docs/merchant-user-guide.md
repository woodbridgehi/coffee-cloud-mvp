# Coffee Terminal 商户使用手册

本文面向门店负责人、店长和被授权的运营人员，说明如何登录商户网站、完成 Windows 咖啡终端模拟器的首次配对，以及日常确认设备状态。

> 本手册适用于软件模拟器。商户不需要、也不应接触设备 Token、MQTT 密码、私钥或平台管理员 Token。

## 1. 使用前准备

### 商户网站

- 商户后台：<https://coffee-api.woodbridge.top/assets/merchant.html>
- 建议使用最新版 Edge、Chrome 或其他现代浏览器。
- 请使用已获授权的商户账号；一个账号可能属于多个组织，登录后可切换可访问的组织。

### Windows 设备

首次配对电脑需要满足：

- Windows 10 或 Windows 11；
- 已安装 Microsoft Edge WebView2 Runtime；
- 能访问商户网站和云端服务；
- 当前 Windows 用户对本机 `LocalAppData` 有写入权限。

发布版通常从以下文件启动：

```text
CoffeeTerminal\CoffeeTerminal.exe
```

不要直接从安装包中拷贝、编辑或替换凭证文件。首次运行后，软件会在当前 Windows 用户的本地应用数据目录创建自己的运行数据。

## 2. 登录商户后台

1. 打开商户后台链接。
2. 输入用户名或已验证邮箱，以及密码。
3. 点击“登录”。
4. 登录后确认顶部显示的是正确组织；如账号有多个组织，在组织切换处选择本次要管理的门店所属组织。

新商户可使用“创建组织账号”完成注册。注册成功只表示已创建商户组织和账号，**不表示已拥有设备**；设备仍需按下一节完成配对。

登录失败时，优先检查：

- 用户名/邮箱是否输入正确；用户名通常不区分大小写；
- 密码是否正确；
- 账号是否已被停用，或尚未完成可用状态验证；
- 当前浏览器是否阻止了本站 Cookie。商户会话使用安全的 HttpOnly Cookie，清除网站数据后需要重新登录。

## 3. Windows 设备首次配对

### 3.1 在 Windows 设备上启动终端

1. 解压完整发布目录，不要只复制单个 `CoffeeTerminal.exe`。
2. 双击 `CoffeeTerminal\CoffeeTerminal.exe`。
3. 第一次启动会显示“设备首次配对”窗口。软件会自动创建本机软件身份、模拟器序列号、云端设备 ID 和短时配对码。
4. 保持此窗口打开，记录窗口中显示的配对码；不要把配对码发到公开群聊或截图中。

配对码是一次性、短时有效的确认码，不是设备密码。若已过期，在设备窗口点击“重新生成配对码”。

### 3.2 在商户后台确认设备

1. 在商户后台进入“我的设备”。
2. 点击“配对新设备”。若看不到该按钮，请联系组织 OWNER 或管理员授予设备配对权限。
3. 填写设备屏幕显示的配对码。
4. 选择设备所属门店。
5. 输入便于门店识别的设备名称，例如“朝阳店吧台模拟器”。
6. 点击“确认配对”。

商户后台会提示设备已配对并等待设备领取凭证。此时不要重复提交配对码，也不要把平台管理员的激活码填入此表单。

### 3.3 等待自动接入并重启

1. 回到 Windows 设备窗口，状态会从“等待商户确认”变为“正在自动接入”。
2. 软件自动领取 HTTP 与 MQTT 运行凭证，并以当前 Windows 用户的 DPAPI 保护方式保存到本机。
3. 显示“设备已完成配对”后，关闭窗口。
4. 再次启动 `CoffeeTerminal.exe`，即可进入咖啡终端主界面。
5. 回到商户后台“我的设备”，确认设备已出现在所选门店，且状态会在短时间内更新为在线。

## 4. 日常运营检查

建议开店前完成以下检查：

1. 登录商户后台，确认当前组织和门店正确。
2. 在“我的设备”查看设备在线状态、最近心跳和门店归属。
3. 在 Windows 终端确认主界面可以打开，网络状态正常。
4. 确认菜单、库存和订单状态与门店当前运营安排一致。
5. 若设备刚配对完成，先等待其完成首次连接，再发起真实演示订单。

设备离线时，先确认 Windows 电脑未休眠、网络正常、终端程序仍在运行。恢复网络后通常会自动恢复连接；不需要重新配对。

## 5. 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 商户后台没有“配对新设备”按钮 | 当前账号缺少设备配对权限。请切换到正确组织，或联系组织 OWNER/平台管理员。 |
| 提示配对码无效、已使用或过期 | 配对码为一次性短时码。回到 Windows 首次安装页生成新码，再重新提交一次。 |
| 商户已确认，但设备仍显示等待 | 在设备窗口点击“刷新配对状态”，确认电脑可以访问云端；不要重复创建多个设备窗口。 |
| 配对成功后终端仍停留在安装页 | 关闭首次安装窗口后重新启动应用。 |
| 设备在线后又离线 | 检查电脑电源/睡眠状态、网络和终端进程；恢复后等待心跳更新。 |
| 更换 Windows 用户或重装系统后不能继续使用 | 运行凭证受当前 Windows 用户的 DPAPI 保护，不能直接复制到新用户或另一台电脑。请在新环境重新执行首次配对，或联系平台管理员处理设备迁移。 |
| 找不到或误删本地数据 | 不要手动还原他人电脑的凭证目录。重新安装后按首次配对流程处理。 |

## 6. 安全要求

- 不要索要、记录、传播设备 Token、MQTT 用户名/密码、私钥或平台管理员 Token。
- 不要把配对码、设备窗口或后台会话截图发到公开渠道。
- 不要将真实凭证写入 `device.json`、Excel、聊天记录或 Git 仓库。
- 操作结束后，在公用电脑上退出商户后台；不要让浏览器长期保留共享会话。
- 设备丢失、疑似被复制、账号异常或凭证可能泄露时，立即停止使用并联系平台管理员进行设备停用或凭证轮换。

## 7. 平台管理员协作边界

商户负责选择门店、命名设备并确认配对。以下事项应由平台管理员处理：

- 创建或停用平台设备记录；
- 处理旧版激活码、设备生命周期、异常迁移或凭证轮换；
- 调整商户的组织、成员角色和设备配对权限；
- 排查云端服务、支付、MQTT 或硬件集成故障。

商户与平台沟通时，请提供设备名称、门店名称、设备屏幕显示的非敏感状态信息和发生时间；不要提供密码或任何凭证内容。

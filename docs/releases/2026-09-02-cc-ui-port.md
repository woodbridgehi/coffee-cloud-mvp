## 二、新范式要点

- **页面范式**：每视图 `cc-titlebar`（标题 + 描述 + 操作）+ `cc-toolbar` 工具栏 + `cc-tablewrap` 表格（局部横向滚动）；总览为「状态摘要条 + 双栏（指标网格 / 告警队列）+ 最近订单」。
- **全局范围条**：组织 / 门店 / 日期区间 / LIVE-TEST 环境从顶栏迁入 `cc-scopebar`（粘性）。
- **组件体系**：`cc-btn`（44px 命中区）/ `cc-status`（流程态圆点）/ `cc-tag`（分类态胶囊）/ `cc-dialog`（弹窗，焦点圈定 + Esc + 焦点归还）/ `cc-drawer`（抽屉）/ `cc-toast` / `cc-secret`（一次性秘密暗色域）/ `cc-timeline` / `cc-chartbox`（图表自带数据表 disclosure）。
- **新增便利**：⌘K 命令面板（索引有权限视图）、移动端底导航 + 「更多」面板、密码显隐切换。
- **CSP 合规**：原型 71 处内联 `onclick` 全部转为 `addEventListener`；无外链资源、无构建步骤。
- **data-od-id**：关键区域标记随移植带入 SPA DOM，供后续 Open Design 迭代对照。
